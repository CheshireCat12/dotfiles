# Configure Kitty terminal

## Mapping:

<kbd>Super</kbd> = <kbd>Ctrl</kbd> + <kbd>Shift</kbd>

| Keys                            | Action   |
| :------------------------------ | :------- |
| <kbd>Super</kbd> + <kbd>1</kbd> | Zoom in  |
| <kbd>Super</kbd> + <kbd>-</kbd> | Zoom out |
|                                 |    |
| <kbd>Super</kbd> + <kbd>t</kbd> | Open new tab in current path  |
| <kbd>Ctrl</kbd> + <kbd>t</kbd>  | Open new tab |
| <kbd>Super</kbd> + <kbd>right</kbd>  | Move to next tab |
| <kbd>Super</kbd> + <kbd>l</kbd>  | Move to next tab |
| <kbd>Super</kbd> + <kbd>left</kbd>  | Move to previous tab |
| <kbd>Super</kbd> + <kbd>h</kbd>  | Move to previous tab |
|                                 |    |
| <kbd>Super</kbd> + <kbd>d</kbd> | Detach terminal  |

## Utils:

Change Font with `$ kitty list-font`.
